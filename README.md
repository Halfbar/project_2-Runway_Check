# 🎭 Fashion Show

A small 2D casual game about choosing the right outfit before stepping onto the runway.

You are backstage at a fashion show. Each round gives you a new set of clothing requirements. Choose the appropriate outfit, walk onto the runway, and find out how the audience reacts.

🌹 **Correct outfit:** roses

🍅 **Wrong outfit:** tomatoes

## 🎮 Gameplay

Each round follows a simple loop:

**Requirements → Choose clothes → Walk the runway → Get evaluated → New round**

The game randomly generates clothing requirements for each round. Your goal is to match them using the available clothing options. 
The project focuses on a simple clothing-swapping and outfit-checking system rather than complex gameplay.

## 🎯 Project Goal

This game was created as a **one-week team prototype**.

The main goal was not to create a large or polished game, but to answer a technical question:
> Can a clothing system be implemented quickly and in a way that allows new clothing items to be added without rewriting the core gameplay logic?
During development, we experimented with:

* visual layers for clothing;
* resource-based clothing data;
* dynamically generated requirements;
* separating clothing data from requirement checking;
* simple game-state management;
* working within a strict time limit.

## 📅 Development

**Start:** August 20, 2026
**Finished:** August 29, 2026

The original target was one week. Development changed to a solo project partway through, and the remaining work was completed independently.
The project was intentionally kept small so that the core mechanic could be implemented and the game could reach a publishable state.
